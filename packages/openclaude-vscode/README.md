# OpenClaude VS Code Surface

This package is a local, no-provider VS Code extension manifest and render-contract surface for product-quality gating.

It is not published, installed, deployed, product-launched, or claimed as available. The current verified boundary is manifest shape, local package dry-run smoke, local mock-host runtime smoke, real local VS Code Extension Development Host command smoke, real local Tree View workbench smoke evidence including TreeItem command execution, and mock-host WebviewView render-contract smoke evidence.

## Scoped Contributions

- Commands: `openclaude.openChat`, `openclaude.runSelection`, `openclaude.explainSelection`, `openclaude.openRuntimeDoctor`
- Tree Views: `openclaude.chatView`, `openclaude.traceEvidenceView`
- Webview Views: `openclaude.controlCenterView`
- Configuration: `openclaude.providerProfile`, `openclaude.permissionMode`, `openclaude.telemetryAllowed`, `openclaude.traceCaptureEnabled`

## Claim Boundary

This package does not authorize provider calls, live model calls, external service calls, marketplace publishing, extension installation, launch, release readiness, public readiness, external validation, production readiness, or autonomous reliability claims.
