# Primary Source Research Ledger Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development for the validator slice and superpowers:verification-before-completion before publishing. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the Autonomous Goal OS primary-source research ledger using Meta's raw/wiki/decision pattern, with local no-provider validation that keeps public claims source-backed and bounded.

**Architecture:** Add a reusable `docs/research` brief format and a narrow TypeScript validator. The validator scans current Goal OS research briefs, requires the source ledger to include local authority docs plus official/original external sources, rejects secondary/blog domains as final evidence, and writes a product-quality report that feeds the existing primary-source registry.

**Tech Stack:** Bun test, TypeScript scripts, Markdown research docs, existing product-quality JSON/Markdown reports.
