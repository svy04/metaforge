# Metaforge Public Proof Pack

Date: 2026-06-18
Status: public-facing, proof-bounded marketing aid

## One-Line Position

Metaforge is a Meta/MFH/Orchestra operating system for evidence-gated agent
work. OpenClaude is the local CLI runtime substrate. Mimesis Engineering is the
source-first loop that imports proven structure from products, papers, patents,
standards, and maintained open-source projects before Metaforge makes stronger
claims.

## Current Proof Level

The current public proof level is:

```text
local no-provider product-quality evidence + research/eval ledger gates + public repository/profile positioning
```

This allows Metaforge to market:

- Meta/MFH/Orchestra as the public operating frame.
- OpenClaude as the local CLI substrate, not the thesis.
- Mimesis Engineering as a source-first improvement loop.
- local research and eval gates that make source absorption auditable.
- public profile/repo surfaces that carry explicit claim boundaries.

This does not prove hosted deployment, public adoption, production readiness,
external validation, compliance, autonomous reliability, or benchmark
superiority.

## Metaforge Proof Tour

Use this path when checking whether the public story is real:

1. **Goal Kernel** turns owner intent into `CG-*.md` goals with scope,
   non-goals, success criteria, validation commands, evidence artifacts,
   rollback rules, and MFH/Meta fields.
2. **Meta** keeps authority sources, decision-ledger links, raw sources, and
   memory/wiki boundaries attached to the goal.
3. **MFH** blocks premature closure through `scripts/validate-goals.ts`,
   `scripts/validate-goal-traces.ts`, and claim-boundary reports.
4. **Orchestra** is the runtime-wired layer where current
   `src/services/orchestra/` behavior and product-quality reports support
   routing claims.
5. **Mimesis Engineering** absorbs load-bearing structure from source ledgers,
   research briefs, eval briefs, OSS, standards, papers, patents, and product
   patterns.
6. **OpenClaude** supplies terminal tools, provider routes, MCP, slash commands,
   streaming, and credential surfaces. It is the substrate, not the public
   thesis.
